# REJEX - Custom Java Regular Expression Engine (Regex & DFA Library)

Мощная и гибкая Java-библиотека для работы с регулярными выражениями и конечными автоматами. Поддерживает прямой синтаксический анализ, компиляцию регулярных выражений напрямую в детерминированные конечные автоматы (ДКА / DFA) без промежуточного НКА (NFA), минимизацию автоматов, теоретико-множественные операции над языками (пересечение, разность, проверка на изоморфизм), поиск с группами захвата, а также обратное восстановление регулярных выражений из автоматов методом $K$-путей.

---

## 💡 Особенности и возможности

### 1. Синтаксис и метасимволы
* **Алфавит:** Поддержка всех printable ASCII и Unicode символов.
* **Экранирование:** Использование метасимвола `%` вместо классического `\` (например, `%*`, `%|`, `%(`, `%%`).
* **Эпсилон (пустая строка):** Специальный символ `$` определяет пустую подстроку ($\varepsilon$).
* **Операторные скобки:** `(r)` для явного задания приоритета операций.

#### Поддерживаемые операции:
| Операция | Синтаксис | Описание |
| :--- | :--- | :--- |
| **ИЛИ (Альтернатива)** | `r1\|r2` | Метасимвол `\|` |
| **Конкатенация** | `r1r2` или `r1.r2` | Опциональный явный оператор `.` |
| **Замыкание Клини** | `r*` или `r…` | Повторение 0 или более раз (метасимволы `*` и `…`) |
| **Позитивное замыкание** | `r+` | Повторение 1 или более раз |
| **Диапазон символов** | `[a1-an]` | Символ из указанного набора/диапазона (например, `[a-z0-9]`) |
| **Повтор в диапазоне** | `r{x,y}` | Повторение от `x` до `y` раз (`r{x,}`, `r{,y}`) |
| **Нумерованная группа захвата** | `(r)` | Автоматическая нумерация групп в порядке следования |
| **Прогностический оператор (Lookahead)** | `r1/r2` | Положительный правый контекст (сопоставление `r1`, только если далее следует `r2`) |

---

### 2. Алгоритмы и Теория автоматов
* **Direct Regex-to-DFA Compilation:** Построение ДКА напрямую из синтаксического дерева регулярного выражения (сопоставление nullable, firstpos, lastpos, followpos) без перехода через НКА (Thomson / NFA).
* **DFA Minimization:** Автоматическая минимизация полученного ДКА (алгоритм Хопкрофта).
* **K-Path Algorithm:** Восстановление алгебраического регулярного выражения из скомпилированного ДКА методом $K$-путей.
* **Теоретико-множественные операции над формальными языками (выполняются над ДКА):**
  * **Пересечение ($L_1 \cap L_2$):** Построение автомата-произведения (Product Automaton).
  * **Разность ($L_1 \setminus L_2$):** Построение дополнения и пересечения автоматов.
  * **Проверка двух автоматов на изоморфизм**

## 🛠️ Основной API и Использование

### 1. Компиляция в ДКА (DFA) и повторное использование

по умолчанию регулярное выражение компилируется в ДКА, если есть в группы захвата - ещё и в НКА

```java
import pattern.*;
import searcher.SearchResult;

// Компиляция РВ -> ДКА -> Минимальный ДКА и РВ -> НКА
Pattern pattern = Pattern.compile("(cat|dog){1,3}%!");

// Выполнение поиска скомпилированным автоматом
SearchResult result = pattern.search("My pet is a catdog!");
if (result.isSuccess()) {
    System.out.println("Match: " + result.getBegin() + result.getEnd());
}

```

---

### 3. Работа с группами захвата (Capture Groups)

Библиотека поддерживает нумерованные группы захвата с доступом через специальные итераторы и оператор индексации:

```java
import pattern.*;
import searcher.SearchResult;

String p = "([a-z]+)%.([0-9]+)"; // Группа 1: буквенный имя, Группа 2: цифры
String text = "Data: item.12344";

SearchResult result = Pattern.compile(p).search(text);

if (result.isSuccess()) {
    // Доступ по индексу
    System.out.println("Группа 1: " + result.group(1)); // "item"
    System.out.println("Группа 2: " + result.group(2)); // "12344"

    // Итерирование по всем захваченным группам
    result.forEach(g -> System.out.println(g);
}

```

---

### 4. Восстановление регулярного выражения из ДКА (K-Path)

Вы можете обратно преобразовать скомпилированный автомат в эквивалентное регулярное выражение:

```java
Pattern pattern = Pattern.compile("a(b|c)*d");

// Восстановление РВ из автомата
String reconstructedRegex = pattern.decompile();
System.out.println("Реконструированное РВ: " + reconstructedRegex);

```

---

### 5. Операции над языками автоматов (Пересечение, Разность и проверка на изоморфизм)

Скомпилированные ДКА позволяют выполнять операции над формальными языками:

```java
Pattern p1 = Pattern.compile("[a-z]+");
Pattern p2 = Pattern.compile("cat|dog").getDfa();

// Пересечение языков (L1 ∩ L2)
Pattern intersection = p1.intersect(p2);

// Разность языков (L1 \ L2)
Pattern difference = p1.difference(p2);

System.out.println("Пересечение принимает 'cat': " + intersection.search("cat").isSuccess()); // true
System.out.println("Разность принимает 'cat': " + difference.search("cat").isSuccess());   // false

```
